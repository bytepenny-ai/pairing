Prompt cache

The engine keeps what it has read of each chat, so the next message reads only what's new. A change to the chat's notes or skills normally makes it read again from that point to the end. Choose how they are laid out, so a change costs as little reading as possible. It applies to every chat from its next message.

Only for chat models that can't call tools (one that can reads the skill itself, with no embedding model). Each question is compared in meaning with each skill not added yet (0 unrelated, 1 the same). Short replies like "OK" add none. The mark suits paraphrase-multilingual-MiniLM-L12-v2 (best for chats in several languages) and all-MiniLM-L6-v2 (English only). multilingual-e5 doesn't suit it: every question scores high there, so every skill is added. A skill's text never goes on a message with an image: it would hide the image.
