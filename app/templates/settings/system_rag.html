RAG (Knowledge base)

Applies to every user's own document uploads (Settings > Knowledge). The per-file limit also applies to shared/global uploads; the storage quota doesn't.

, the active engine, has no embedding models, so the knowledge base can't be used while it is active, even with RAG enabled. Switch to an engine with embeddings to use it.

Enable RAG (Knowledge base) for users

Off disables uploading/deleting documents on the Knowledge tab for every user and stops chats from searching it — affects every inference engine the same way, regardless of whether it could technically support embeddings. Remember to press Save below.
