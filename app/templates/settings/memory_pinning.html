Memory pinning

A pinned model loads when its Matricxon server starts and stays in memory: it is never unloaded for being idle or to make room, and chats for it go to a server that has it pinned. A pin is a wish, not a reservation: when a pin cannot load, that memory is used as usual.

Memory pinning works only when the engine is Matricxon. Choose it under Admin settings > Inference > Engine.
